# Teddy 1.3.0 计划

## 目标

1. 把告警通知目标从"每次新建任务手工粘贴"改成可复用的配置。
2. 让导航栏的"系统配置"从占位入口变成可用页面。
3. 机器人地址不进入源码和仓库，历史泄露的凭据不再从代码侧扩散。

## 范围

- 新增 `notify_config` 表，支持多条配置，并保证全局最多一条默认项。
- 新增系统配置页：列表、新增、编辑、删除、设为默认。
- 任务配置页新增"填入默认通知"按钮，点击后取默认项填入机器人地址输入框。
- 导航栏"系统配置"接入实际页面；四个页面统一。

## 边界

- 只覆盖企业微信机器人地址；告警邮件抄送的默认值不在本次范围。
- 机器人地址在系统配置页完整显示（该页面已由后端会话鉴权保护）。
- 沿用静态页面 + jQuery，不引入前端构建链。
- 不升级 Java、Spring Boot、Spark、MyBatis 或前端依赖。
- 新增表为向后兼容变更，老版本 Teddy 不认识该表，不影响既有部署。

## 迁移

`DataBaseInit` 启动时探测 `notify_config` 是否存在，不存在则创建。升级时无需手工执行 DDL。

## 待确认

- 是否需要配置的启用/停用状态或排序。
- 是否需要把告警邮件的默认值也纳入同一套配置。
